# csg-heal-lab

**把 CSG 布尔结果从「有缺陷的三角汤」构造性修复成水密壳：120/120 个注入缺陷实例修复后 0 边界边 / 0 非流形边 / 0 绕序冲突，体积相对解析 voxel 计数误差 ≤ 1e-12（实测最大 1.61e-16）；基线（不修复，`baseline/none.mjs`）0/120 有效。** 但在 250,000 条构造射线中修复后仍有 **40 条（0.016%）** 与解析实心判定不一致，基线是 1,257 条（0.503%）——这个残差如实写进限制，不包装成 0。

Upstream: none

## 这是什么

CSG（布尔并/差）输出经常不是水密壳：接缝顶点没焊、T-junction、面翻转、重复面、退化面、孔洞、整壳内外翻转。`src/core.mjs` 是纯 ES module（不 import three、不碰 DOM/IO），做三件事：

1. **审计**：边界边、非流形边、绕序冲突、T-junction（顶点落在边内部）、退化/重复面、未引用顶点、内外翻转壳，每类给出计数与 witness。
2. **构造性修复**：相对 eps 焊点 → 去退化/重复 → BFS 统一绕序 + 按有向体积翻正壳 → 迭代拆分 T-junction → 边界环质心扇补洞 → 压缩顶点。
3. **双 oracle 复证**：散度定理体积 vs 解析 voxel 计数；射线绕数（winding number）判内外 vs 解析 voxel 实心。所有阈值都是 bbox 对角线的相对量。

示例语料是 12 个网格对齐的 CSG 实心（box 并/差，`tools/gen-sample.mjs` 光栅化），每个实心注入 10 类缺陷之一，共 **120 例**。`data/corpus.json` 只存 voxel 与注入参数，网格每次由 core 重建，生成器确定性。

## 怎么跑（一条命令）

```bash
node tools/gen-sample.mjs && node bench/verify.mjs && node bench/bench.mjs
```

浏览器：`python3 -m http.server 4173`，打开 <http://localhost:4173>（three r169 由固定版本 importmap 从 jsDelivr 加载，无构建步骤、无 `node_modules`）。

## 证据（`bench/result.json` 与 `bench/verify.mjs` 实跑）

| 指标 | 修复后 | 基线（不修复） |
|---|---|---|
| 实例有效（水密 + 无重复/退化/未引用/翻转壳） | **120/120** | **0/120** |
| 注入缺陷被 witness 检出 | **120/120** | — |
| 体积 vs 解析 voxel 计数（相对误差 ≤1e-12） | **120/120**，最大 **1.61e-16** | — |
| 250,000 条射线与解析实心不一致的射线数 | **40（0.016%）** | **1,257（0.503%）** |
| 尺度 1e-6 / 1e-3 / 1 / 1e3 / 1e6（3 实心 × 4 缺陷 × 5 尺度） | **60/60** 仍水密且体积精确 | — |
| 修复耗时（8 次采样，warmup 1） | 冷启动 **7.6 ms**；120 例中位 **149.4 ms**（**1.245 ms/例**），p95 230.1 ms，RSD **18.2%** | — |

`bench/verify.mjs` 输出 **9 项断言全过**（含独立 O(F²) 重复面 oracle 24/24 一致、20/20 重复修复确定性）。RSD 18.2% 的来源：每轮只有 ~150 ms 的短负载，受 V8 GC/共享 4 核主机影响；同轮 min 142.5 ms 与 p95 230.1 ms 一并公布。250,000 条射线耗时 **5,100.6 ms（20.4 µs/条）**，覆盖 760,290 个区间采样点、510,290 个绕数变化点。射线中 1/5 构造为精确命中三角形边中点、1/5 命中面心，其余为随机射线。

## 本轮创新

**B 档**：把「缺陷分类 → 构造性修复 → 双 oracle 复证」做成一个闭环，而不是又一张缺陷表。已有 `csg-result-oracle-lab` 只判定 9 类注入缺陷、`clearance-repair-lab` 只修间隙、`union-volume-lab` 只做体积积分；本仓库新在**修复后可执行、可复算**：同一份 `src/core.mjs` 既给 node 出数与断言，也给浏览器 HUD 现场重算并与 node 烘焙的 `data/ref.json` 比对（页面显示 MATCHES/MISMATCH）。射线判定没有用朴素奇偶+去重（在边/顶点命中上会数错），而是用**有向绕数**：边命中两条相邻面同向算一次进入、一正一反算擦边零次。

## 已知限制（必须读）

- **射线残差不是 0**：250,000 条中 40 条仍不一致（0.016%），集中在精确命中边/顶点的构造射线上；我未把这 40 条解释成「可忽略」，也不改口径去迁就承诺。基线 1,257 条提供对照。
- 语料是**网格对齐的 box 并/差**（voxel 化 CSG），不是任意曲面 CSG；`src/core.mjs` 的修复对三角网格通用，但证据只覆盖这一族。
- 补洞用**质心扇**，只对平面边界环几何精确；非平面边界环会改体积（本轮语料只删单个面，环都是平面的）。
- 相对阈值：焊点 `1e-6·bboxDiag`、T-junction/共线 `1e-9·bboxDiag`、退化面积 `1e-12·bboxDiag²`。小于这些尺度的特征会被合并/判退化；已在 1e-6…1e6 五档缩放下验证结论不变。
- 审计对**有内腔**的实心会把内壳判成「翻转壳」（按有向体积符号），因此语料排除了内腔体；这是已知的判定盲区。
- 浏览器只做了 HTTP 200 + importmap 可达性验证，**没有**真实 GPU 像素级截图（环境禁止 headless browser）。
- 未实现非流形边（>2 面）修复：审计会报，但修复器不猜哪张面该删；本轮 10 类缺陷不含它。

